## 启动采样

每架构先预热两对，再交替采样六对；计时从创建进程到 `WaitForInputIdle` 返回，包含进程创建与演示初始化，不等同于首帧耗时。当前机器同时运行其它任务，仅用于检查明显回退，不据此宣称压缩提升性能。

## 扫描与验证边界

本机 Defender 服务和杀毒引擎未启用，因此本机专门扫描明确记录为 `unavailable`，没有更改安全设置或添加排除项。发现的其它安全软件登记信息不等于专门扫描通过。

GitHub Actions 在引擎可用时对实际发布 exe 执行 Defender 自定义只检测扫描，记录引擎签名版本和退出码；发现威胁或扫描错误会阻止发布，不可用时明确记录而不冒充通过。每次构建的实际扫描结果见 `windows-x64-validation` 验证附件中的 `defender-scan.json`。

本机结果不等于干净 Windows 10/11、全部杀毒软件或真实联网账户的完整兼容性验收。发布仍只提供一个 exe，无新增应用运行时依赖。
