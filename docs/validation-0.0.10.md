## README 兜底

- About 和 Topics 均缺失时，通过已验证 Token 后台读取 GitHub 的首选 README。限制为 64 KiB 前缀，去除图片、链接和 HTML 标签，保留不超过 2,400 UTF-8 字节的节选，加入现有预算组批，无额外模型调用阶段。
- 旧“资料不足”记录在下次增量整理时自动检查 README。全量数量包含全部已 Star 项目，不再提前排除无 About 的项目；启动不会自动联网概括。
- README 404 需确认 Contents 可以读取；若根目录同样 404，再核对提交接口返回的明确空仓库响应。权限隐藏的 404、403、401、网络失败、限流和非法编码均保留待重试，不能误报资料不足。个别仓库权限失败不阻塞其它有效项目；限流停止继续抓取 README。
- 节选及检查指纹逐项原子保存，保存失败即停止；模型失败、取消或重启后继续增量时复用已保存节选。仓库新推送触发 README 复查，节选未变不再次调用模型；全量与单项目重做刷新 README。摘要指纹仅包含实际摘要来源，不改变画像分类的元数据指纹。
- 不跟随 README 的链接或图片，不执行其中的指令，不匿名回退，不抓取其它项目文件。私有 README 需要 Token 的 Contents 读取权限。
