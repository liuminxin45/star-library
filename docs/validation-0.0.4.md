# 0.0.4 验证记录

## 交付范围

- 画像正文合并为一段向内探索的叙事，证据保留在内部；六维仅显示比例，点击仍能查看项目依据。
- 只有“更新画像”一个入口，运行中为“分析中…”。删除画像操作、覆盖率说明和项目计数已移除。
- 不新增旧画像文风转换、旧版展示分支或升级引导。未变更的分类仍按实际来源指纹复用，避免重复分析。
- 发现的两次普通 Chat Completions 调用之间，由应用执行三路 GitHub REST 搜索；无需模型提供搜索工具。
- 规划与精选使用六维、叙事、代表性依据、内部兴趣偏好和不感兴趣反馈。关联维度、探索意图、查询与实搜候选一起校验。

模拟接口验证：

- 普通模型不返回工具调用，应用仍执行三路实搜，均衡去重后最多 30 个候选；精选最多 4 core / 2 adjacent，按 core / core / adjacent 排列。
- 六维存在时，不要求另有技术兴趣关键词；单一非零维度可以完成发现。无可靠分类时，在请求模型和搜索前提示更新画像。
- 搜索计划拒绝重复查询、覆盖不足、重复或无效维度、零证据维度和私有项目名称。
- 精选拒绝虚构或重复 ID、非候选关联维度、缺失中文概括及无效字段；搜索错误、不完整搜索、模型限流、取消均不替换上一批。
- 分类逐项目保存、部分错误跳过、叙事失败或保存失败的数据保护与分类续接仍通过；完整画像只在叙事证据校验通过后替换。
- 新叙事拒绝仓库名、ID、链接路径和换行，内部证据继续验证真实项目及资料充分性。

自动测试仅使用隔离数据和模拟网络，不调用真实模型，不修改真实 GitHub Stars。

## 视觉检查

使用明确标有“演示”的固定资料，检查浅色、深色、980×700 小窗口、125% 缩放模拟和维度依据展开：

- 正文连续呈现，不再插入项目名和证据链接；六条比例尺只有维度名称与百分比。
- 叙事以自主安排日常、理解与改变事物、秩序和未知之间的选择为线索，避免职业、专业能力和固定人格断言。
- 小窗口可滚动，标题和唯一更新操作保持可用；依据中的项目仍可进入对应星库卡片。

视觉结果属于固定资料演示，不作为真实模型生成质量的证明。宣传页与 README 不新增模拟结果截图；新版真实截图待用户手动更新画像与发现后补充。
