# AI 请求预算

中文概括与画像分类按项目长度动态组批，继续分别保留 20 / 40 项的数量上限。

- 初始内部预算为 8,192 tokens；输入与输出各最多 3,072，预留四分之一余量。这是保守估算，不是对任意模型上下文大小的承诺。
- 输入仅包含项目 ID、名称、About、语言和最多八个 Topics；概括缺少 About / Topics 时以最多 2,400 UTF-8 字节的 README 节选替代 About，分类额外保留最多八个标签。短字段、空字段省略，正常 About 仍最多 1,600 UTF-8 字节。
- 概括目标 25—50 字、最多 80 字；输出使用短字段，资料不足用 null，保存时还原为正式摘要字段。
- 根据每批数量预留输出，并根据明确的参数不支持错误有限回退 max_tokens / max_completion_tokens / 不传输出参数。不进行额外能力探测。
- 仅官方 DeepSeek 地址的整理、分类、叙事与发现请求显式关闭思考模式，不向任意兼容接口添加专属参数。
- 接口有 usage 时校准保守估算系数；按接口和模型指纹保存预算、缩批结果及输出参数选择。没有 usage 时不伪造用量。
- 上下文超限时缩减预算；截断、缺失或无效项目最多自动补试两轮。已经保存的项目不再发送。取消、限流、其它网络错误与保存失败不自动反复调用。
- 没有 About 和 Topics 的摘要项目后台读取 README，去除图片、链接和 HTML 标签后进入同一批模型请求，不增加第二次概括调用。确认没有可用 README 内容才本地记录资料不足；权限、编码、网络和限流失败保留待重试。分类仍只使用元数据与标签。
- README 节选先原子保存再调用模型，重启续接无需重复下载。普通同步不使全部概括过期；README 兜底项目在仓库新推送后复查，节选未变则跳过模型。全量或单项目重新概括会刷新 README。
- 最终画像只接收六维全量统计和预算内的代表依据，叙事校验成功才替换整份画像。
