# 0.0.5 验证记录

## 本次行为

- 中文概括按 token 预算动态合批，每次最多 20 项；分类按相同预算器分批。短字段、空字段省略与更短的输出减少重复内容。
- 完整项目逐项保存；截断仅恢复完整对象，缺项最多自动补试两轮，已保存项目不再发送。取消、限流和保存失败停止补试。
- 根据接口 usage 校准估算；上下文不足时缩批，并按接口及模型记录预算与输出参数。无额外 tokenizer、SDK 或运行库。
- 发现先验证 GitHub 连接，再调用 AI。实搜与精选都要求至少 100 Stars，按热度加权，近期“不感兴趣”的相似主题降权；反馈也进入搜索规划和精选。
- 设置页后台检查 GitHub Release，每六小时最多一次；新版本可跳转官方 Release。检查需要已连接 GitHub，不匿名回退，不自动下载安装。
- “Star me”仅在点击后打开项目；已连接 GitHub 时执行明确的 Star 操作，更新本地状态。
- README 精简为作用、优势、真实截图和构建入口；完整操作说明独立保留。

## 验证范围

核心检查覆盖：预算合批、长中文资料缩批、短字段返回、资料不足、截断恢复与缺项续接、两轮补试上限、参数回退、上下文超限、取消、限流、保存失败、乱序并发、分类缓存及真实证据。

发现检查覆盖：三路均执行、均衡取样、仓库去重、100 Stars 边界、低 Stars 排除、负反馈降权、热度单调权重、旧 later 反馈不参与逻辑，以及 Token 失效和账号不匹配时零 AI 调用。

更新与支持检查覆盖：数值版本比较、无 Token、草稿及预发布排除、异常版本字段、隔离预览禁止真实检查、后台结果进入设置、Star me 的模拟写入及本地状态。

自动检查仅使用隔离数据和模拟网络，不调用真实模型，不实际 Star / Unstar，不读取应用真实凭据。新宣传截图使用用户手动更新后的真实数据快照，不使用演示结果。
