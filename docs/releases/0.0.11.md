## 本次更新

- 默认发布 UPX 压缩的单文件程序，保留 GitHub Stars 管理、AI 概括、兴趣画像与项目发现功能。
- 构建固定使用官方 UPX 5.3.0，核对下载包和工具 SHA-256。压缩后验证数据完整性、逐字节解压还原、架构、安全标志及版本资源。
- x64 / x86 自动测试均执行压缩后的核心测试、完整原生 UI 检查及正式程序轻量自检。
- 仍然免安装，仅需一个 exe，不增加应用运行库、后台服务或模型 SDK。

本机 x64 正式程序为 166,912 字节；x86 为 160,256 字节。两种架构各通过 3,325 项核心检查、68 项完整 UI 检查和 10 项打包保护检查，并完成 38 个界面场景和多次隔离启动验证。正式 x64 附件由 GitHub Actions 重新构建，大小与摘要以附件为准。[验证记录](https://github.com/liuminxin45/star-library/blob/main/docs/validation-0.0.11.md)

## 升级

退出旧窗口，下载新 exe 后启动。数据格式和保存策略保持兼容，原收藏、概括、画像及反馈保留；启动不会自动调用模型。

AI 仍使用自行配置的模型服务，可能产生费用，相关仓库资料会发送给该服务。UPX 减小的是分发体积，不代表运行内存同比减少。
