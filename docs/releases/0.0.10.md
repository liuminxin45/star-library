## 本次更新

- **增量 / 全量整理**：“AI 整理 ▾”可补齐新项目与未完成项目，也可确认后重新整理全部已 Star 项目。
- **中断后继续**：成功一个保存一个；失败、取消或重启后，选择增量整理即可续接，已完成项目不重复发送。
- **README 兜底**：没有 About 和 Topics 时自动读取 README，提取限长节选后加入现有批量概括。没有可用资料才标记资料不足；权限、网络和限流错误保留待重试。
- **减少重复消耗**：README 缓存先保存再调用模型；增量复用缓存，重新检查后节选未变则跳过模型。继续支持 1 / 5 / 10 并发和按 token 预算组批。
- **更严格的体积门禁**：正式单文件 exe 不超过 400,000 字节，仅依赖 Windows 系统 DLL。

## 升级后使用

退出旧窗口，用新 exe 启动，再点击“AI 整理 ▾ → 增量整理”。以前因缺少 About 被标记“资料不足”的项目，会补查 README。原收藏、概括、画像和反馈保留，启动不会自动调用模型。

GitHub 功能需要 Token；私有 README 需要 Contents 读取权限。AI 使用自行配置的模型服务，可能产生服务费用，相关元数据和必要的 README 节选会发送给该服务。
