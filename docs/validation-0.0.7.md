# 0.0.7 验证记录

## 发现的纠偏与容错

- 真实收藏主题频率参与搜索规划，六维描述探索方式，不替代技术兴趣。避免把“理解原理”误解为偏好刷题。
- 实搜与精选两层排除练习、课程、作业和项目点子清单；保持至少 100 Stars、热度加权、负反馈降权与具体仓库排除。
- 每路最多搜索两页，首屏候选不足时继续找；仍然只有两次模型调用、最多 30 个候选和 4 core / 2 adjacent。
- 搜索计划缺项、重复、错误维度或响应截断时，保留有效部分，由程序基于真实主题和非零维度补齐三路。隐私与查询安全校验不放宽。
- 精选逐项跳过未知/重复 ID、无效摘要及无效维度；缺少可选维度时使用候选已有的可信关联。截断仅恢复完整对象，全无效时保留旧批次。
- 新推荐只请求 ID、一句中文概括及可选维度，停止生成没有展示入口的标题、点子、理由，避免浪费输出与苛刻文案匹配。

## 设置与清理

- 单行标签字号统一，右侧操作使用相同宽度和对齐线。“★ Star me”使用主按钮强调；仅有新版本时显示“更新”。
- 移除不可达的手动保存、模型说明弹窗、旧“稍后看”查询回退，以及预览中未使用的标题、点子与理由。现有用户数据、备份和恢复机制保留。
