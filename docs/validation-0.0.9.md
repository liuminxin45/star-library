## 增量与全量整理

- “AI 整理 ▾”提供增量与重新整理全部，显示实际处理数量；没有增量待办时禁用该项，仍可全量重做。范围为全部已 Star 项目，不受搜索、语言或列表筛选影响。
- 全量通过系统确认窗口明确开始，默认取消。卡片上的重新概括保持单项目操作。
- 用可选的 `summary_requested` 保存待处理项目的来源指纹。先原子保存待处理记录，再请求模型；已有记录未变化时不重复保存队列。每个成功结果与标记移除在同一次原子保存中提交。
- 取消、限流、个别无效结果、保存失败时，已提交结果保留；未完成项目在重启后仍归入增量。原有有效概括保持显示，直到替代结果校验与保存成功。元数据变化时按最新资料重新请求，过期来源结果不能写入。
- 无 About 和 Topics 的项目本地记录资料不足，不调用模型、不算失败。延续预算合批、最多 20 项、1 / 5 / 10 并发及不完整结果逐项校验机制。
